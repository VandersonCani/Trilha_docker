---

Conceitos compreendidos no módulo:

• O que é um contêiner:
Um contêiner é um ambiente isolado que executa aplicações junto de suas dependências e configurações, garantindo padronização entre diferentes ambientes.

• Diferença entre contêineres e máquinas virtuais:
Máquinas virtuais virtualizam um sistema operacional completo, enquanto contêineres compartilham o kernel do sistema hospedeiro, tornando sua execução mais leve e rápida.

• Por que contêineres são mais leves:
Contêineres utilizam menos recursos por não necessitarem de um sistema operacional completo para cada instância executada.

Conceitos compreendidos no módulo:

• O que é uma imagem Docker:
Uma imagem Docker é um pacote imutável contendo aplicação, bibliotecas, dependências e configurações necessárias para execução de um sistema.

• O que é um contêiner:
Um contêiner é uma instância em execução criada a partir de uma imagem Docker.

• Diferença entre imagem e contêiner:
A imagem representa o modelo estático da aplicação, enquanto o contêiner representa a aplicação em funcionamento.

• O que é Docker Hub:
Docker Hub é um repositório online utilizado para armazenamento e compartilhamento de imagens Docker.
