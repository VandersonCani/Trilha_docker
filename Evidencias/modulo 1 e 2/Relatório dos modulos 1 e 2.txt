MÓDULO 01 – INSTALAÇÃO E VALIDAÇÃO DO AMBIENTE DOCKER

As evidências apresentadas demonstram o processo completo de preparação do ambiente Docker no Windows utilizando WSL2 como backend principal.

As imagens “Instalação wsl.png” e “Instalação wsl_2.png” mostram a instalação e habilitação do Windows Subsystem for Linux (WSL) e do componente VirtualMachinePlatform, necessários para funcionamento do Docker Desktop no Windows 10.

Na imagem “hyperv instalado.png” é possível verificar a análise dos requisitos de virtualização do sistema. Essa etapa foi importante para identificar inicialmente que a virtualização da BIOS estava desativada, impedindo a inicialização correta do Docker. Após ativação da virtualização no firmware da máquina, o Docker Desktop conseguiu iniciar normalmente.

A imagem “Hello world e docker version.png” demonstra duas validações importantes:

* execução do comando `docker --version`, confirmando instalação correta do Docker Desktop;
* execução do comando `docker run hello-world`, validando comunicação entre Docker Client, Docker Daemon e Docker Hub.

Já a imagem “confirmação execução helloworld.png” evidencia o fluxo completo de funcionamento do Docker:

* download automático da imagem hello-world;
* criação do contêiner;
* execução do processo interno;
* finalização automática do contêiner após conclusão da tarefa.

As evidências demonstram também a compreensão dos conceitos fundamentais abordados no módulo:

* funcionamento básico do Docker;
* diferença entre contêineres e máquinas virtuais;
* utilização de virtualização através do WSL2;
* execução do primeiro contêiner Docker.

O conjunto das atividades comprova que o ambiente foi configurado corretamente e que o Docker está funcional para continuidade da trilha.


MÓDULO 02 – IMAGENS E CONTÊINERES

As evidências deste módulo demonstram o entendimento do funcionamento das imagens Docker e do ciclo de vida dos contêineres.

A imagem “docker images.png” apresenta a execução do comando `docker images`, permitindo visualizar a imagem `hello-world:latest` armazenada localmente após download automático realizado pelo Docker Hub.

Essa etapa permitiu compreender que imagens Docker funcionam como modelos imutáveis contendo aplicações, bibliotecas e dependências necessárias para execução de um sistema.

A imagem “containers recentes docker.png” demonstra a execução do comando `docker ps -a`, exibindo o contêiner criado a partir da imagem hello-world.

O status “Exited (0)” confirma que:

* o contêiner foi criado corretamente;
* o processo interno executou sem erros;
* o contêiner encerrou normalmente após finalizar sua tarefa.

As evidências também demonstram a diferença prática entre imagem e contêiner:

* a imagem permanece armazenada localmente;
* o contêiner representa a instância executada da imagem.

Durante a atividade foi possível compreender o fluxo básico do Docker:

* download da imagem;
* criação do contêiner;
* execução;
* finalização do processo.

As atividades realizadas atenderam os objetivos propostos no módulo, permitindo compreender a relação entre Docker Hub, imagens e contêineres.
